# 🎄 Spotify Christmas Music Streaming Analysis (2017–2025)

![Image](https://github.com/user-attachments/assets/53c31e10-dc1f-495e-b85f-8978c88851f7)

## Overview

This project analyzes Christmas music streaming trends on Spotify from 2017 to 2025, focusing on seasonal listening patterns, year-over-year performance, and songs that are rising or declining in popularity.

## Tools

Python, Microsoft Excel, Power BI, DAX, Data Visualization, Time-Series Analysis

## Dataset

Spotify Christmas streaming data (Kworb), 2017–2025

## Key Insights

Strong seasonal streaming spikes from mid-November to Christmas

Classic tracks dominate streams across multiple years

Indexed analysis reveals growth and decline beyond raw stream counts
